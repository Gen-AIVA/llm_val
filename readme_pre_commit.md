# Pre-commit hooks: ruff, mypy, semgrep

Этот документ описывает, как использовать pre-commit с настроенными линтерами
для поддержания качества кода в проекте.

## Установка

1. **Установите pre-commit и сразу необходимые библиотеки: ruff, mypy, semgrep** (один раз на машину):
   ```bash
   pip install pre-commit ruff mypy semgrep
   ```

2. **Установите Git‑хуки** в локальный репозиторий:
   ```bash
   pre-commit install
   ```
   После этого при каждом `git commit` будут автоматически запускаться проверки
   для изменённых файлов.

3. **Обновите хуки до актуальных версий** (опционально):
   ```bash
   pre-commit autoupdate
   ```

## Структура конфигурационных файлов

- `.pre-commit-config.yaml` – описание хуков, порядок запуска.
- `code-rules.yaml` – пользовательские правила для Semgrep.
- `mypy.ini` – настройки статической типизации mypy.
- `pyproject.toml` – настройки ruff (форматтер и линтер).

Все файлы должны находиться в корне репозитория.

## Запуск проверок вручную

Запустить хуки **только на изменённых (staged) файлах** (аналог того,
что происходит при коммите):
```bash
pre-commit run
```

Если нужно проверить конкретный файл/директорию, передайте их как аргументы:
```bash
pre-commit run --files src/llm_val/val_test/tools/*.py
```

## Запуск только отдельных инструментов

Каждый хук имеет идентификатор (`id`). Список доступных хуков:
- `ruff-format` – форматирование кода Ruff.
- `ruff-lint` – линтинг Ruff (с автоисправлением).
- `mypy` – статическая типизация.
- `semgrep` – кастомные правила Semgrep.

Запустить только один из них:
```bash
pre-commit run ruff-lint
pre-commit run mypy
pre-commit run semgrep
```

Можно комбинировать с флагом `--files` для выборочной проверки.
