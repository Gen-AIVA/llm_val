## Ноутбуки с примерами работы с библиотекой

В директории `examples` представлены ноутбуки с примерами работы с библиотекой. 
В тетрадках *.0 описаны основные концепции, идеи и примеры применений используемых абстракций, а в *.1 - подробное описание, как реализовывать свои имплементации используемых абстракций. 
Увидеть все реализованные тесты с примерами использования можно в ноутбуке `5.2.All_Test_example.ipynb`. Обязательно читайте описания к тестам в этом ноутбуке! Также крайне желательно ознакомиться с докстрингами к переменным в главных функциях теста в коде тестов.
Узнать о том, как запускать несколько тестов подряд и получать результаты в одном файле вместе с красивой экселькой, можно в ноутбуке `6.0.Aggregator_example.ipynb`.

У каждого центра есть свои креды, которые нужно вставлять в переменные RQUID и AUTH_DATA. Если вы не знаете креды вашего центра, можете обратиться к Ване Подпружникову.

В корне репозитория лежат файл `requirements_freezed.txt`, в котором лежит список библиотек, на котором были успешно прогнаны на cloud.ru все имеющиеся юнит-тесты в библиотеке (версия Python - 3.9.13). 

Помимо непосредственно тестов, в директории `examples/s3_obm_update` в ноутбуке представлен код с прогоном моделей GigaChat на тестовом сете, выгрузкой результатов прогонов в S3 и добавлением тестового сета в OBM/S3.

В библиотеке баг? Хочешь предложить улучшение? Можешь написать комментарий к этой таске: https://jira.delta.sbrf.ru/browse/MFB2DLSN4N-110 , а можешь сделать pull request, если уже получилось исправить баг самостоятельно!

## Структура библиотеки

Иерархия и описание директорий и файлов в библиотеке:
- model - Различные реализации моделей:
    - GigaModel.py - родительский класс, от которого должны наследоваться все реализации моделей;
    - BaseGigaModel.py - простейшая реализация модели;
    - MultiThreadGigaModel.py - простейшая многопоточная реализация модели;
    - ...
- sampler - Различные реализации sampler'ов:
    - Sampler.py - родительский класс, от которого должны наследоваться все реализации sampler'ов;
    - MMLUSampler.py - пример sampler'а для MMLU-датасетов;
    - RuBQSampler.py - пример sampler'а для RuBQ-датасетов;
    - ...
- scorer - Различные реализации scorer'ов:
    - Scorer.py - родительский класс, от которого должны наследоваться все реализации scorer'ов;
    - UniversalScorer.py - пример скорера;
    - ...
- val_test - Валидационные тесты:
    - data_quality - тесты на качество данных;
    - model_quality - тесты на точность модели;
    - ...
- utils - Вспомогательные штуки для работы библиотеки:
    - api.py - класс, реализующий функционал API GigaChat'а;
    - metrics.py - словари и реализации функций для подсчета метрик;
    - ssl_context.py - контекстный менеджер для выключения проверки ssl сертификата;
    - lib_vars.py - внутренние переменные для работы библиотеки;
    - report_helper.py - функции для помощи в составлении report'a;
    - ...

## Нейминг параметров:

"Строгие" названия параметров, верные для всех тестов:
- sampler - семплер;
- scorer - скорер;
- model - модель;
- data_type - название выборки (train/val/test/oot);
- metric_name - название метрики;
- metric_agg - способ агрегации метрики;
- semaphore_threshold - трешхолды светофоров;
- greater_is_better - верно ли, что чем больше метрика, тем лучше;
- is_info - тест информационный или нет.
